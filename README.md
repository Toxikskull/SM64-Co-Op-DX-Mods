# SM64-Co-Op-DX-Mods

# Simple SavePoints
Host-managed multiplayer savepoints. Each connected player has an independent savepoint. Dpad Down: create your savepoint. L Trigger + Dpad Down: load your savepoint. The host persists each player's savepoint separately in mod_storage. Made by Toxikskull & GazzyGaz.

# Simple SavePoints Reloaded
Each connected player has independent savepoints. Dpad Up/Down/Left/Right: create your savepoints. L Trigger + Dpad Up/Down/Left/Right: load your savepoints. Vibecoded by GazzyGaz & debugged by Toxikskull.
